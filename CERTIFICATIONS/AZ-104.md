# Adminitster Identity 
## Azure Entra ID
- identity and access management
- = center of applications
- access to
	- m365
	- dropbox
	- concur
	- salesforce
- ssrp
	- self service password reset (SSRP)
- authentication
	- single sign on (SSO)
### concepts
- identity
	- any object that can be authenticated
		- user
		- group
		- managed identity (identity of a service within AZ)
			- identity of a VM
		- service principle
			- same as service accounts on prem
			- execute on behalf of user
- account
	- associate data attribute to identity
	- example
		- user will have multiple attributes
			- address
			- phone number
- entra ID account
	- created in entra ID / another AZ cloud service
	- example
		- work or school account
		- personal microsoft account
- entra ID / tenant / directory
	- dedicated instance of entra ID
	- created during microsoft cloud service
	- tenant = directory
### editions
- entra ID
	- queried using http/https
	- saml / ws-federation / openID connect / oath
- active directory domain services
	- queried using ldap
	- kerb
